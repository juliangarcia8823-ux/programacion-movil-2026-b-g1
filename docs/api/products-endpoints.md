# Endpoints /api/products

- `GET /api/products`: Lista productos. Soporta `?search=` y `?category=`.
- `GET /api/products/:id`: Retorna un producto por ID.
- `POST /api/products`: Crea un producto.
- `PUT /api/products/:id`: Reemplaza/Actualiza un producto.
- `DELETE /api/products/:id`: Elimina un producto (Responde 204).
