# Entidad Product

- `id`: Entero incremental autogenerado.
- `name`: Texto no vacío (máx 60 caracteres).
- `price`: Número strictly mayor a 0.
- `category`: Cadena exacta (`Bebidas`, `Snacks`, `Aseo`, `Hogar`).
- `stock`: Entero mayor o igual a 0.
- **Persistencia**: N/A, almacenamiento en memoria.
